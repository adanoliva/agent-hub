01

Plataforma e infraestructura

Runtime
Electron (Node.js embebido, Chromium para UI)
Distribución
Portable .exe — sin instalador, sin Node.js requerido
Sistema operativo
Windows (objetivo principal)
Backend
Express embebido en el proceso principal de Electron
Puerto
localhost:3737
Actualizaciones
Manual — descargar nuevo .exe de GitHub privado y reemplazar
System tray
La app vive en la bandeja del sistema. Minimizar cierra la ventana pero la app sigue activa. Click derecho en el icono → menú contextual (Abrir, Reiniciar, Salir).
Rutas portables
Toda la configuración, agentes y caché se generan en la carpeta donde se ejecuta el .exe. El proyecto es 100% portable — mueve la carpeta y funciona.
Rutas de proyectos externas
Los proyectos de desarrollo (Unity, React, etc.) pueden estar en cualquier ruta del sistema — no necesitan estar dentro de la carpeta de la app. Solo se registra la ruta en la configuración.

Estructura de ficheros

Carpeta de la app (donde está el .exe) claude-dev-manager/ claude-dev-manager.exe config.json ← configuración, proyectos registrados, hashes agents/ global/ ← nivel 1: agentes para todos los proyectos code-reviewer.md git-helper.md ... section-games/ ← nivel 2: agentes por categoría section-web/ section-mobile/ section-docs/ tech-games-unity/ ← nivel 3: agentes por tecnología tech-web-react/ tech-mobile-react-native/ ... cache/ suggestions.json ← sugerencias cacheadas de IA por nivel Cada proyecto (en cualquier ruta del sistema) C:/ruta/al/proyecto/ CLAUDE.md ← contexto del proyecto para Claude Code .claude/ agents/ ← nivel 4: agentes propios + copias de 1-3 code-reviewer.md ← copia del global unity-dev.md ← copia del tech mi-agente-custom.md ← exclusivo del proyecto
Los proyectos son autónomos
Claude Code solo lee {proyecto}/.claude/agents/. Todos los agentes aplicables (niveles 1-3) se copian físicamente ahí al crear o importar el proyecto. No hay dependencias externas.

05

Sistema de sincronización

Copia física al crear/importar proyecto — todos los agentes de niveles 1-3 aplicables se copian a {proyecto}/.claude/agents/. El manager guarda un hash SHA-256 del contenido de cada copia en config.json.
Los agentes de nivel 4 (propios del proyecto) nunca participan en el sync — son intocables.
Detección de cambios — al editar un agente en niveles 1-3 o crear uno nuevo, el manager compara el hash actual con el de cada copia en cada proyecto. Si difieren → estado "Actualización disponible".
Los agentes nuevos aparecen como "pendiente de copiar" en proyectos que deberían tenerlos.
Estados visibles por agente en la vista de proyecto:
Al día Actualización disponible Solo este proyecto
Sincronización — opción C (global + por proyecto)
Botón "Sync todos" en la vista de Agentes → propaga todos los cambios a todos los proyectos.
Botón "Sync" en cada proyecto → solo ese proyecto. Ambas opciones siempre disponibles.
Badge de pendientes en la vista de Proyectos — cada card de proyecto muestra un badge numérico con las actualizaciones pendientes. A golpe de vista sabes qué proyectos necesitan sync sin entrar en ellos.
06

Creación de agentes

Modo manual
Rellenas todos los campos directamente: nombre, descripción, modelo, herramientas y system prompt. Control total sobre el resultado.
Modo asistido por IA
Escribes una descripción breve. La app llama a Claude con contexto del nivel actual y genera un system prompt completo, optimizado y listo para editar antes de guardar.

Flujo modo asistido

Descripción breveEj: "Experto en UI/UX que genera interfaces con HTML y CSS"
Selector idiomaES · EN
Claude generaSystem prompt completo adaptado al nivel y categoría
Revisar y guardarEditable antes de confirmar
Idioma del system prompt: ES o EN
El meta-prompt enviado a Claude incluye: nivel del agente, categoría/tech, herramientas seleccionadas, agentes ya existentes en ese nivel (para no duplicar) e idioma elegido.
Requiere API key de Anthropic
Se configura en el wizard del primer arranque. Guardada en config.json. Editable desde Ajustes. Sin API key, el modo manual siempre está disponible.
07

Sugerencias de agentes por IA

Aparecen en todos los niveles — al navegar a cualquier nivel en la vista de Agentes (global, categoría, tech o proyecto), se muestran 2-4 cards de sugerencias junto a los agentes existentes. Visualmente diferenciadas: borde discontinuo, ligeramente atenuadas.
Cacheadas — las sugerencias se generan una sola vez por nivel y se guardan en cache/suggestions.json. No se gasta tokens en cada visita.
El botón "Sugerir más" reemplaza las sugerencias cacheadas por un nuevo lote. No es acumulativo.
Contextuales y no repetitivas — el prompt incluye la lista de agentes ya existentes en ese nivel. Claude no propone nada que ya esté creado ni variantes redundantes.
Click para crear — al pulsar una card sugerida, se abre el formulario pre-rellenado con los datos de la sugerencia. El usuario puede editar antes de confirmar. Al guardar, la sugerencia desaparece del panel.
08

Gestión de proyectos

Crear nuevo proyecto
Elige nombre, categoría y tecnología. La app crea la carpeta en la ruta indicada, genera la estructura base, copia los agentes aplicables y escribe el CLAUDE.md con plantilla según la tech elegida.
Importar proyecto existente
Apunta a una carpeta ya existente. La app registra el proyecto, crea .claude/agents/ si no existe, copia los agentes y actualiza el CLAUDE.md si no lo tiene.

Metadatos por proyecto

Nombre
string
Categoría
games|web|mobile|docs
Tecnología
unity|react|rn|...
Estado
active|paused|archived

Acciones dentro de un proyecto

Editar agentes del nivel 4 (propios). Ver agentes de niveles 1-3 copiados con su estado de sync.
Editar CLAUDE.md con editor de texto integrado. Guardado directo al fichero.
Botón "Abrir en VS Code" → ejecuta code {ruta}. Si code no está en PATH, muestra instrucciones.
Botón "Abrir carpeta" → abre el Explorador de Windows en la ruta del proyecto.
Botón "Sync" → sincroniza solo este proyecto con los agentes actualizados de niveles 1-3.
09

Navegación e interfaz

Vista Proyectos
Cards agrupadas por categoría. Badge de sync pendientes. Filtro por estado. Click → panel de detalle del proyecto con todas las acciones.
Vista Agentes
Árbol colapsable estilo VS Code en sidebar. Panel central con cards del nivel activo + sugerencias. Panel lateral con editor al seleccionar un agente.

Árbol de navegación — Vista Agentes

▼ Global ← nivel 1 code-reviewer git-helper + [2 sugeridos] ▼ Categorías ▼ Juegos ← nivel 2 ▼ Unity ← nivel 3 unity-dev unity-shader + [2 sugeridos] ▶ Godot ▶ Web ▶ Móvil ▶ Docs ▼ Proyectos ← nivel 4 (por proyecto) ▶ Mi RPG (Unity) ↑2 ← badge de actualizaciones ▶ Mi App Web (React)
Tema visual
Oscuro fijo, estilo VS Code. #0d0d0f fondo, #141416 sidebar, acentos en violeta/verde/ámbar según nivel de jerarquía.
Tipografía
UI general en Syne. Código, nombres de agentes y rutas en JetBrains Mono.
