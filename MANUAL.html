Claude Dev Manager

Guía completa para gestionar tus agentes de Claude Code, organizar proyectos y mantener contexto por proyecto — todo desde una interfaz visual.

primeros pasos

Instalación

Claude Dev Manager es un ejecutable portable — no requiere instalador ni Node.js.

1
Descarga el ejecutable
Descarga claude-dev-manager.exe desde la sección Releases del repositorio privado de GitHub.
2
Colócalo en su carpeta definitiva
Crea una carpeta para la app y mueve el .exe ahí. Toda la configuración y los agentes se generarán en esa misma carpeta. Ej: C:\Tools\ClaudeDevManager\
Elige bien la carpeta desde el principio
Si mueves el .exe después, la configuración y los agentes se quedan en la carpeta original. Lo más seguro es moverla carpeta completa.
3
Ejecuta y sigue el wizard
Haz doble clic en el .exe. El wizard de primer arranque te guía en la configuración inicial.
primeros pasos

Primer arranque

La primera vez que ejecutas la app, un wizard de 3 pasos configura todo lo necesario.

1
Bienvenida
Presentación de la app y resumen de lo que puedes hacer con ella. Haz clic en Comenzar.
2
API key de Anthropic
Introduce tu API key de Anthropic. La necesitas para el modo asistido por IA y las sugerencias de agentes. Si no la tienes ahora, puedes saltarte este paso y configurarla más tarde desde Ajustes.
¿Dónde consigo mi API key?
En console.anthropic.com → API Keys → Create Key. La key tiene el formato sk-ant-api03-...
3
Generación de estructura base
La app crea todas las carpetas necesarias y carga los agentes por defecto en todos los niveles. Este proceso tarda unos segundos. Al terminar, la app está lista para usar.
Agentes pre-cargados desde el primer minuto
Tras el wizard, ya tienes 20+ agentes listos — globales, por categoría y por tecnología. No necesitas crear nada para empezar a trabajar con Claude Code.

la aplicación

Jerarquía de niveles

Los agentes se organizan en cuatro niveles. Cada proyecto hereda físicamente los agentes de los niveles superiores que le aplican.

1
Global
Agentes que aplican a todos los proyectos sin excepción. Aquí viven los agentes de uso universal: revisor de código, ayudante de Git, escritor de tests, escritor de documentación y el agente de refactorización.
2
Categoría
Agentes que aplican a todos los proyectos de una categoría (Juegos, Web, Móvil, Docs). Por ejemplo, el agente game-designer solo tiene sentido en proyectos de la categoría Juegos.
3
Tecnología
Agentes específicos de una tecnología concreta. unity-dev solo aplica a proyectos Unity, react-dev solo a proyectos React, etc.
4
Proyecto
Agentes exclusivos de un proyecto concreto. Nunca participan en el sync — son intocables y solo tú los gestionas. Úsalos para lógica muy específica de ese proyecto.
Los agentes de nivel 4 son tuyos
Ninguna sincronización global puede modificarlos ni eliminarlos. Son 100% independientes.
tareas frecuentes

Crear un proyecto

Proyecto nuevo
La app crea la carpeta, la estructura base y el CLAUDE.md con plantilla según la tecnología elegida. Los agentes aplicables se copian automáticamente.
Importar existente
Apunta a una carpeta que ya existe en tu sistema. La app añade .claude/agents/ si no existe y copia los agentes correspondientes.

Pasos — Proyecto nuevo

1
En Vista Proyectos → botón "Nuevo proyecto"
2
Rellena el formulario
Nombre del proyecto, categoría, tecnología concreta y ruta donde crear la carpeta.
3
La app genera todo automáticamente
Carpeta del proyecto, CLAUDE.md con plantilla adaptada a tu tecnología y copia de todos los agentes aplicables en .claude/agents/.
4
Abre en VS Code y empieza
Desde la card del proyecto → botón VS Code. Claude Code ya tiene acceso a todos los agentes y al contexto del CLAUDE.md.
tareas frecuentes

Crear un agente

Navega al nivel donde quieres crear el agente en la Vista Agentes y pulsa "+ Nuevo agente".

Modo manual
Rellenas todos los campos directamente. Tienes control total sobre el nombre, descripción, modelo, herramientas y system prompt.
Modo asistido por IA
Describes el agente en una frase. Claude genera el system prompt completo teniendo en cuenta el nivel y los agentes existentes.

Modo asistido — paso a paso

1
Escribe una descripción breve
Ejemplo: "Experto en animaciones Unity con Animator, AnimationTree y Timeline"
2
Selecciona el idioma del system prompt
Elige ES (español) o EN (inglés). Los system prompts en inglés suelen obtener mejores resultados con Claude.
3
Pulsa "Generar con IA"
Claude genera un system prompt completo y bien estructurado. El resultado aparece en el campo de texto, listo para editar antes de guardar.
4
Revisa, ajusta y guarda
El agente se crea en el nivel correspondiente. Si es nivel 1-3, aparecerá como pendiente en los proyectos que lo necesiten.

Sincronizar cambios

Cuando editas un agente de nivel 1-3 o creas uno nuevo, los proyectos muestran una notificación de actualización. Tú decides cuándo aplicarla.

Estados de un agente en un proyecto

Al día
La copia en el proyecto es idéntica a la fuente. No hay nada que hacer.
Actualización
La fuente ha cambiado desde la última copia. El agente puede mejorarse.
Solo proyecto
Agente de nivel 4. No tiene fuente superior. Nunca se toca en sync.

Cómo sincronizar

Sync global
Botón en la Vista Agentes. Propaga todos los cambios pendientes a todos los proyectos de una vez.
Sync por proyecto
Botón en la card de cada proyecto (solo aparece si tiene actualizaciones). Actualiza solo ese proyecto.
El sync sobrescribe las copias en el proyecto
Si has editado manualmente un agente copiado directamente en la carpeta del proyecto (no desde el manager), esos cambios se perderán al sincronizar. Usa el nivel 4 para personalizaciones permanentes de un proyecto.
tareas frecuentes

Sugerencias de IA

En cada nivel del árbol de agentes aparecen 2-4 cards sugeridas por Claude, adaptadas al contexto y sin repetir lo que ya existe.

→
Navega a cualquier nivel
Al entrar a un nivel (global, categoría, tech o proyecto), las sugerencias aparecen automáticamente con borde discontinuo junto a los agentes existentes.
→
Haz clic en una sugerencia para crearla
Se abre el formulario pre-rellenado con nombre, descripción, herramientas y system prompt generado por IA. Edita lo que necesites y guarda.
→
"Sugerir más" para nuevas propuestas
El botón ↻ Sugerir más reemplaza las sugerencias actuales por un nuevo lote. Las sugerencias se cachean — no gasta tokens en cada visita.
tareas frecuentes

Ajustes

Pantalla de configuración accesible desde la barra de navegación superior. Contiene dos secciones.

API key de Anthropic
Muestra la key enmascarada con un botón para cambiarla. Necesaria para el modo asistido de creación de agentes y las sugerencias automáticas.
Categorías y tecnologías
Crea nuevas categorías o añade tecnologías a las existentes. Al crear una nueva, la IA propondrá agentes base que aparecerán como sugerencias en ese nivel.
Añade tus propias tecnologías
¿Empiezas un proyecto con una tecnología no incluida por defecto? Añádela en Ajustes, y el manager generará agentes base específicos para ella mediante IA.
referencia

Preguntas frecuentes

¿Necesito tener Claude Code instalado?
Sí. Claude Dev Manager gestiona los agentes de Claude Code. Necesitas la extensión de Claude Code instalada en VS Code o la CLI de Claude Code para que los agentes funcionen.
¿Puedo usar la app sin API key?
Sí. El modo manual para crear agentes siempre está disponible. Solo el modo asistido por IA y las sugerencias automáticas requieren una API key de Anthropic.
¿Los cambios en agentes se sincronizan automáticamente?
No. Los cambios quedan como "pendientes" y tú decides cuándo sincronizar — por proyecto o todos a la vez con el botón global. Esto evita cambios inesperados mientras estás trabajando.
¿Qué pasa si edito un agente directamente en la carpeta del proyecto?
El manager no detectará ese cambio. La próxima vez que sincronices ese proyecto, la versión del manager sobreescribirá tu edición manual. Para hacer cambios permanentes en un proyecto, créalos como agentes de nivel 4 desde el manager.
¿Puedo mover la app a otra carpeta?
Sí, mueve la carpeta completa (no solo el .exe). Las rutas de los proyectos registrados son absolutas — si también mueves los proyectos, actualiza sus rutas desde la vista Proyectos → editar proyecto.
¿Cómo actualizo la app a una nueva versión?
Descarga el nuevo claude-dev-manager.exe desde el repositorio de GitHub y reemplaza el actual en tu carpeta. La configuración y los agentes se conservan porque están en ficheros separados.
El botón "Abrir en VS Code" no funciona
El comando code necesita estar en el PATH del sistema. Abre VS Code → Command Palette (Ctrl+Shift+P) → "Shell Command: Install 'code' command in PATH". Reinicia la app y vuelve a intentarlo.
