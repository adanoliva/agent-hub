MANUAL DE USO · v1.8.2

Agent Hub

Guía completa para gestionar tus agentes de Claude Code, organizar proyectos y mantener contexto por proyecto — todo desde una interfaz visual.

Construida con IA. Para la IA. Con manos humanas al volante.

Primeros pasos

Instalación

Agent Hub es un ejecutable portable. No requiere instalador ni Node.js en el sistema.

1
Descargar el ejecutable
Ve a la sección Releases del repositorio y descarga agent-hub.exe.
2
Elige una ubicación permanente
Mueve el .exe a la carpeta donde quieras que viva la app — por ejemplo C:\Tools\AgentHub\. Todos los datos (agentes, configuración, caché) se crean en esa misma carpeta.
3
Ejecuta el .exe
La primera vez arranca el wizard de configuración. En ejecuciones posteriores carga directamente la vista de Proyectos.
Portabilidad
Puedes mover toda la carpeta a otro lugar — la app funciona desde cualquier ubicación. Las rutas de los proyectos registrados son absolutas; si mueves los proyectos en disco, actualiza sus rutas desde la app.

Estado General

Contadores de agentes desglosados por nivel (Global, Categoría, Tecnología y Sin categoría) y de proyectos por estado (Activos, Pausados, Archivados). Haz clic en la fila de Agentes o Proyectos para navegar directamente a esa vista.

Sincronización

Tres indicadores de estado: agentes pendientes de sync con tus proyectos, proyectos desactualizados y estado del directorio de agentes externo. El botón Sincronizar todo propaga todos los cambios pendientes a todos los proyectos de una vez.

Salud de Proyectos

Análisis en tiempo real del estado de cada proyecto activo. Cada entrada muestra un indicador de color y el primer problema detectado.

Saludable
Sin incidencias detectadas. Ruta, contexto y agentes en orden.
Advertencia
Sync desactualizado, contexto demasiado corto o agentes sin herramientas configuradas.
Crítico
Ruta del proyecto no encontrada, fichero de contexto ausente o agentes corruptos.

Oportunidades de Mejora

Agent Hub analiza el estado de tus proyectos y genera recomendaciones automáticas. Hay tres tipos:

CRÍTICA
Fichero de contexto ausente (CLAUDE.md o copilot-instructions.md). El botón de acción abre el generador de contexto.
MEJORA
El fichero de contexto existe pero es demasiado corto. El botón lleva al editor del proyecto para ampliarlo.
INFO
Agentes pendientes de sync o proyectos desactualizados. El botón abre la vista o fuerza el sync.
Acción directa desde el dashboard
Cada notificación tiene un botón de acción que ejecuta la mejora directamente, y un botón Aplazar que oculta esa notificación durante 7 días — útil cuando ya sabes que algo es bajo prioridad ahora mismo. Las aplazadas se diferencian de las descartadas en el contador de ocultas.
Navegación directa a agentes
Al hacer clic en una notificación de tipo agente, la app navega automáticamente a la vista de Agentes, selecciona el nodo correcto en el árbol y abre el editor del agente afectado.

Acciones Rápidas

Atajos para las operaciones más frecuentes: crear un agente nuevo, crear un proyecto, sincronizar todo, ir al chat e ir a ajustes. Los botones "Nuevo Agente" y "Nuevo Proyecto" abren directamente el modal correspondiente en la vista destino.

Uso de IA

Registro de tokens consumidos con el proveedor de IA activo, separado en dos bloques: Total acumulado (persistido entre sesiones) y Sesión actual (solo durante la ejecución activa). Muestra tokens de entrada, tokens de salida, número de llamadas y coste estimado en dólares (solo disponible con la API de Anthropic).

Reiniciar sesión
Pone a cero los contadores de la sesión actual. El acumulado total no se toca.
Reiniciar total
Pone a cero todos los contadores, incluido el acumulado persistido en disco.
Coste estimado
El coste en dólares solo está disponible cuando el proveedor activo es la API de Anthropic, que factura por tokens. Con Claude CLI o GitHub Copilot el coste aparece como $0.00.

Historial por proyecto

Cada proyecto tiene su propio historial de conversación. Al cambiar el proyecto activo desde el selector del topbar, el chat actual se guarda y se carga el del nuevo proyecto. El historial global (sin proyecto) se mantiene cuando no hay ningún proyecto seleccionado.

@mention de agentes

Escribe @nombre en el input para añadir un agente como contexto activo. Aparece un dropdown autocomplete con todos los agentes disponibles filtrados por lo que escribes. Los agentes activos se muestran como chips encima del input y su system prompt se incluye automáticamente en cada mensaje enviado.

Combina agentes
Puedes activar varios agentes a la vez. Por ejemplo, @code-reviewer + @unity-dev da como resultado una revisión de código con criterios específicos de Unity.

Indicador de contexto del proyecto

Debajo del selector de proyecto aparece un badge que indica el estado del fichero de contexto (CLAUDE.md o copilot-instructions.md):

Compatible
El fichero de contexto existe y el proveedor configurado en el proyecto coincide con el global.
Mismatch
El proveedor del proyecto no coincide con el proveedor global. El chat funciona, pero puede no ser óptimo.
Sin contexto
El proyecto no tiene fichero de contexto. La IA trabaja sin información específica del proyecto.

Si hay un mismatch de proveedor, aparece un banner ámbar encima del input explicando el conflicto y ofreciendo un enlace rápido a Ajustes para resolverlo.

Acciones sugeridas

La IA puede sugerir acciones al final de sus respuestas que aparecen como botones clicables. Acciones disponibles: Crear agente (abre el editor prerellenado), Ver agentes (navega a la vista Agentes) y Abrir ajustes.

Esta pestaña tiene dos secciones independientes para incorporar agentes externos a la app.

Repositorio GitHub que actúa como fuente de agentes versionados. Agent Hub descarga y mantiene sincronizados todos los agentes del repositorio. Configura la URL del repo, activa o desactiva la sincronización y lanza un sync manual cuando quieras. Si el repo actualiza un agente que tú también has modificado localmente, aparece un conflicto que puedes resolver eligiendo mantener tu versión o actualizar con la del directorio.
Importar agente puntual
Importa un único agente desde cualquier URL que devuelva un fichero .md con frontmatter válido. Útil para incorporar un agente concreto sin añadir todo un repositorio. Consulta la sección Importar agente externo para el flujo completo.

La aplicación

Jerarquía de niveles

Los agentes se organizan en cuatro niveles. Los tres primeros participan en el sistema de sync; el cuarto es exclusivo del proyecto.

1
Global
Aplica a todos los proyectos sin excepción. Estos agentes también se sincronizan automáticamente a ~/.claude/agents/ para que estén disponibles en cualquier proyecto desde la CLI de Claude Code, aunque no esté registrado en Agent Hub.
2
Categoría
Aplica a todos los proyectos de esa categoría (Juegos, Web, Móvil, Docs, etc.). Útil para agentes específicos del dominio pero no de una tecnología concreta.
3
Tecnología
Aplica solo a proyectos con esa tecnología dentro de la categoría (Unity, React, React Native, Next.js, etc.).
4
Proyecto
Exclusivo de ese proyecto. Se crea y edita desde el árbol seleccionando el proyecto, o directamente desde el drawer. Nunca participa en el sistema de sync — Agent Hub no lo toca al sincronizar.
Tareas frecuentes

Crear / importar proyecto

Crear un proyecto nuevo

1
Pulsa "Nuevo proyecto" en la barra superior
Se abre el modal de creación.
2
Rellena el formulario
Nombre, categoría, tecnología (opcional), ruta base donde crear la carpeta y estado inicial. Agent Hub genera la carpeta con un slug a partir del nombre.
3
Agent Hub lo configura
Crea la estructura de carpetas, un CLAUDE.md vacío y copia todos los agentes aplicables (global + categoría + tecnología) a .claude/agents/. Registra los hashes de cada copia.

Importar un proyecto existente

Pulsa Importar. Introduce el nombre, categoría y la ruta de la carpeta existente. Agent Hub registra el proyecto y copia los agentes aplicables sin modificar los archivos que ya existen. Si la carpeta ya tiene agentes propios en .claude/agents/, los detecta como agentes de nivel 4 (local).

Tareas frecuentes

Drawer de proyecto

Haz clic en cualquier tarjeta de proyecto para abrir el drawer lateral. Contiene todas las opciones de gestión de ese proyecto en tres pestañas.

screenshots/drawer-proyecto.png Drawer del proyecto con las tres pestañas

Pestaña CLAUDE.md

Editor de texto para el fichero CLAUDE.md del proyecto. Este fichero es el contexto que Claude Code carga automáticamente al trabajar en ese proyecto. Pulsa Guardar para escribir los cambios en disco.

También puedes generar el contenido automáticamente con IA — consulta la sección Generar contexto del proyecto.

Pestaña Agentes

Lista todos los agentes del proyecto con su estado de sincronización. Al abrir el drawer se carga automáticamente un preview dry-run que muestra cuántos agentes se añadirán, actualizarán o ya están al día — sin escribir nada en disco todavía.

ok
El agente está actualizado. El hash del fichero coincide con el maestro en Agent Hub.
actualizar
El agente maestro cambió. Hay una versión más reciente disponible.
nuevo
Agente aplicable que aún no fue copiado. Aparecerá tras la siguiente sync.
local
Agente de nivel 4 propio del proyecto. Agent Hub no lo modifica durante el sync.

Excluir un agente

Al excluir un agente desde el drawer aparece un modal con dos opciones:

Excluir y eliminar archivo
Borra el .md del disco del proyecto. El agente queda marcado como excluido y no volverá a copiarse en futuras syncs.
Solo excluir
El archivo permanece en disco pero Agent Hub lo ignora en syncs futuras. Útil para desactivar un agente sin perder su contenido.

Pestaña Info

Edita los metadatos del proyecto: nombre, categoría, tecnología, ruta, descripción y estado. También muestra sugerencias de agentes específicas para ese proyecto basadas en su CLAUDE.md.

Tareas frecuentes

Crear un agente

Desde la vista Agentes, selecciona el nivel donde quieres crear el agente y pulsa "Nuevo agente". El editor se abre en un modal flotante — haz clic fuera del modal o pulsa Cancelar para cerrarlo sin guardar.

screenshots/editor-agente.png Editor de agente con el panel de generación IA
1
Selecciona el nivel en el árbol
Haz clic en Global, en una categoría, en una tecnología o en un proyecto según dónde deba vivir el agente.
2
Pulsa "Nuevo agente"
El editor se abre en blanco. Rellena el nombre (identificador en kebab-case), la descripción y el modelo.
3
Elige las herramientas
Marca las herramientas que el agente necesita: Bash, Read, Write, Edit, Grep, WebFetch, etc. Usa solo las imprescindibles.
4
Escribe o genera el system prompt
Escribe el system prompt manualmente, o usa Generar con IA: describe el agente en una frase y pulsa "Generar". Agent Hub llama al proveedor de IA y rellena el textarea con el prompt generado.
Selector de idioma
Usa el selector ES / EN para que el system prompt generado salga en español o inglés. La descripción que escribes puede estar en cualquier idioma.
5
Guarda el agente
Pulsa "Guardar". Agent Hub escribe el fichero {nombre}.md en el directorio del nivel seleccionado y actualiza los hashes de los proyectos afectados.
Tareas frecuentes

Optimizar agente con IA

Para agentes ya existentes con system prompt propio, Agent Hub puede pedir a la IA que mejore el prompt y la descripción manteniendo el foco original del agente.

1
Abre el agente en el editor
Haz clic en cualquier agente existente que tenga system prompt. El botón Optimizar con IA aparece en la barra de acciones del editor.
2
Pulsa "Optimizar con IA"
Agent Hub envía al proveedor de IA el nombre, descripción, system prompt actual, herramientas y modelo. La IA devuelve una descripción mejorada y un system prompt optimizado.
3
Revisa y guarda
El editor se actualiza con los nuevos valores. Revísalos y pulsa Guardar. El fichero queda marcado con optimized: true en el frontmatter y el botón de optimizar desaparece para indicar que ya está optimizado.
Un solo uso por agente
El botón de optimizar solo aparece si el agente no ha sido optimizado previamente (optimized: true ausente). Si quieres volver a optimizarlo, edita el frontmatter manualmente y elimina ese campo.
Tareas frecuentes

Sincronizar cambios

Cuando editas un agente de los niveles 1-3, los proyectos que lo tienen copiado quedan marcados con actualizaciones pendientes. El sync copia la versión actualizada a esos proyectos.

El sync es manual y explícito
Agent Hub nunca sobrescribe los ficheros de tus proyectos sin que lo pidas. Tú decides cuándo sincronizar. Esto evita cambios inesperados mientras trabajas.

Opciones de sync

Sync todos
Botón en la barra superior de la vista Proyectos. Propaga todos los cambios pendientes a todos los proyectos de una vez.
Sync proyecto (tarjeta)
Botón en la tarjeta de un proyecto concreto, visible solo cuando hay pendientes.
Sync desde drawer
Botón en el drawer del proyecto, pestaña Agentes. Muestra además el estado detallado de cada agente.
Tareas frecuentes

Sugerencias de IA

Agent Hub consulta al proveedor de IA para sugerir agentes útiles en cada contexto. Hay dos tipos de sugerencias: por nivel y por proyecto.

Sugerencias por nivel

Al seleccionar un nodo en el árbol de la vista Agentes, Agent Hub sugiere 2-4 agentes que podrían ser útiles en ese nivel (global, categoría o tecnología). Aparecen en la cuadrícula como tarjetas punteadas con la etiqueta sugerido. Haz clic en una para pre-rellenar el editor.

Sugerencias por proyecto

En el drawer de cada proyecto, la pestaña Info muestra sugerencias de agentes específicas para ese proyecto. Agent Hub lee el CLAUDE.md del proyecto como contexto principal y genera sugerencias adaptadas a su arquitectura y tecnología concreta.

Caché inteligente y sin repeticiones
Las sugerencias se cachean para no gastar tokens en cada visita. Agent Hub nunca sugiere agentes que ya existen en ese nivel. Al pulsar Sugerir más, las sugerencias que ya estaban visibles también se excluyen — no recibirás los mismos resultados dos veces.
Las sugerencias desaparecen al guardarlas
Cuando guardas una sugerencia como agente real, la tarjeta desaparece de la cuadrícula de sugerencias automáticamente. No necesitas refrescar la vista.
Tareas frecuentes

Generar contexto del proyecto

Agent Hub puede analizar la estructura de tu proyecto y generar automáticamente el fichero de contexto para IA.

CLAUDE.md
Fichero de contexto para Claude Code. Se guarda en la raíz del proyecto y Claude Code lo carga automáticamente.
copilot-instructions.md
Fichero de contexto para GitHub Copilot. Se guarda en .github/.
1
Abre el drawer del proyecto
Haz clic en la tarjeta del proyecto y ve a la pestaña CLAUDE.md.
2
Pulsa "Generar con IA"
Agent Hub analiza el directorio del proyecto: detecta lenguajes por extensión de archivo, lee package.json, requirements.txt o pyproject.toml, detecta framework de testing, linting, build tool, CI/CD y Docker.
3
Revisa el contenido generado
El resultado aparece en el editor para que lo revises y edites antes de guardar. Pulsa Guardar para escribirlo en disco.
Revisar antes de guardar
El contenido generado es un punto de partida. Revísalo y ajusta lo que no sea correcto — la IA puede inferir mal la arquitectura del proyecto si no tiene suficiente información en los ficheros de configuración.
Tareas frecuentes

Importar agente puntual

Importa un único agente desde cualquier URL que devuelva un .md con frontmatter válido. Accede desde Ajustes → Directorio de Agentes → Importar agente puntual.

1
Introduce la URL
Pega la URL directa al fichero .md del agente. Puede ser un raw de GitHub, un Gist o cualquier URL que devuelva el texto del fichero.
2
Pulsa "Importar"
Agent Hub descarga el fichero y lo parsea. Si tiene frontmatter válido, extrae nombre, descripción, modelo, herramientas y system prompt automáticamente.
3
Revisa el preview
Aparece un modal con todos los campos del agente parseado. Puedes editar cualquier campo antes de guardarlo.
4
Elige el destino y confirma
Selecciona en qué nivel guardar el agente (Global, Categoría o Tecnología). Agent Hub guarda el agente en disco y participa en el sistema de sync como cualquier otro agente del nivel elegido.
Tareas frecuentes

Actualizaciones automáticas

Agent Hub comprueba si hay una nueva versión cada vez que arranca. La actualización es opt-in — nada se descarga ni instala sin tu confirmación.

1
Comprobación automática al arrancar

Usar agentes en VS Code

Los agentes gestionados por Agent Hub se usan directamente en Claude Code dentro de VS Code. No necesitas ningún paso adicional — Agent Hub ya los ha copiado en los lugares correctos.

Ver agentes disponibles

/agents

Lista completa de agentes disponibles en el proyecto actual y los globales de ~/.claude/agents/.

Invocar un agente directamente

@code-reviewer revisa PlayerController.cs @unity-dev crea un sistema de inventario con ScriptableObjects @test-writer genera tests para AuthService.ts

Escribe @nombre-del-agente seguido de la tarea. Claude Code carga el system prompt del agente y trabaja con ese contexto especializado.

Delegación automática

Si describes una tarea sin @, Claude Code puede seleccionar el agente más apropiado basándose en el campo description de cada agente. Por eso es importante que las descripciones sean precisas.

Dónde viven los agentes

global
~/.claude/agents/ — disponibles en cualquier proyecto, aunque no esté registrado en Agent Hub.
proyecto
{proyecto}/.claude/agents/ — disponibles solo cuando trabajas en ese proyecto.
Requiere Claude Code
Para usar agentes necesitas tener la extensión Claude Code instalada en VS Code o la CLI de Claude Code. Agent Hub gestiona los ficheros pero no instala Claude Code por ti.
Referencia

Preguntas frecuentes

¿Necesito tener Claude Code instalado?
Sí. Agent Hub gestiona los agentes de Claude Code. Para usarlos necesitas tener la CLI de Claude Code instalada y configurada (~/.claude/). En modo manual puedes crear agentes sin proveedor de IA, pero solo tienen efecto si Claude Code está instalado.
¿Puedo usar Agent Hub sin configurar ningún proveedor de IA?
Sí. El modo manual siempre está disponible: puedes crear, editar, organizar y sincronizar agentes sin ningún proveedor. Solo las funciones de generación de system prompts, optimización, sugerencias, chat y generación de contexto requieren un proveedor configurado.
¿Los agentes se sincronizan automáticamente cuando los modifico?
No. Agent Hub marca los proyectos afectados con el badge de actualizaciones pendientes, pero tú decides cuándo aplicar el sync. Esto evita que cambios en los agentes lleguen a tus proyectos mientras estás trabajando en ellos.
¿Qué pasa si borro un agente de nivel global?
El fichero se elimina del directorio agents/global/ del manager y de ~/.claude/agents/. En los proyectos que tenían ese agente, la copia en .claude/agents/ queda intacta hasta que ejecutes un sync.
¿Cuál es la diferencia entre "excluir y eliminar" y "solo excluir"?
"Excluir y eliminar" borra el fichero .md del directorio .claude/agents/ del proyecto. "Solo excluir" mantiene el fichero en disco pero Agent Hub lo ignora en syncs futuros — el agente sigue disponible en Claude Code hasta que lo borres manualmente.
¿Puedo mover la carpeta del .exe a otro lugar?
Sí, Agent Hub es completamente portable. Mueve toda la carpeta (con config.json, agents/ y cache/) al nuevo lugar y ejecuta el .exe. Las rutas de los proyectos son absolutas — si también mueves los proyectos, actualiza sus rutas desde la app.
¿El auto-update funciona con el .exe portable?
Sí. electron-updater soporta portables. Al instalar la actualización, reemplaza el .exe existente con el nuevo. Tus datos (config.json, agents/, cache/) no se tocan — están junto al .exe, no dentro de él.
¿Qué diferencia hay entre "Nuevo proyecto" e "Importar"?
Nuevo proyecto crea la carpeta en el sistema de ficheros desde cero. Importar registra una carpeta que ya existe — útil para proyectos que ya tienes en disco y quieres empezar a gestionar con Agent Hub.
¿Funciona en macOS o Linux?
La app está desarrollada y probada en Windows 10/11. Electron es multiplataforma, pero el build actual genera solo .exe. Con ajustes en electron-builder.yml podría compilarse para macOS (.dmg) o Linux (.AppImage).
