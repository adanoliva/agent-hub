Agentes en tres niveles

Cada agente es un .md con frontmatter YAML. La jerarquía determina dónde se aplican automáticamente.

Skills que se eligen solas

Agent Hub lee el stack del proyecto (package.json, pom.xml, go.mod, Dockerfile…, también en monorepos) e inyecta las skills que tocan en cada ejecución. Con Claude Code se instalan además como skills nativas. Añade a mano las genéricas o genera las tuyas con IA.

react typescript postgresql vue docker unity + tu propia skill

Cualquier motor, el mismo resultado

Cambia de proveedor sin rehacer nada: agentes, skills, contexto del proyecto y orquestaciones funcionan igual con un CLI nativo o con una API. Los CLIs trabajan dentro del proyecto como desde tu terminal; con las APIs, Agent Hub les da las herramientas para leer, escribir y ejecutar. El botón Prueba real de Ajustes comprueba de punta a punta que tu proveedor lee un proyecto.

Dashboard de estado

Panel central con salud de proyectos, notificaciones priorizadas (críticas / optimización), seguimiento de tokens y coste, y acciones rápidas. Sin ruido.

Un contexto para todos

Genera el contexto del proyecto con IA y Agent Hub lo escribe como AGENTS.md, que leen Claude Code, Copilot y Antigravity, además de CLAUDE.md y equivalentes. Cada ejecución lo usa siempre.

Agentes desde la terminal

Lanza cualquier agente sobre un proyecto sin salir de tu terminal. Se instala con un clic desde Ajustes, sin Node ni permisos de administrador, y usa el mismo proveedor, skills y servidores MCP que la app (que debe estar abierta). Ctrl+C detiene el agente al momento.

$ agent-hub projects
$ agent-hub agents -p api
$ agent-hub run -p api -a test-writer "cubre src/auth"

02
Pipelines multiagente
en paralelo.

Define grafos DAG donde varios agentes corren simultáneamente. El motor calcula los niveles topológicos y ejecuta cada nivel en paralelo con Promise.allSettled.

DAG con canvas visual

Arrastra y conecta agentes en un lienzo 2D. Las aristas Bézier muestran el flujo de datos entre pasos.

Gates HITL — control humano

Pausa el pipeline antes de un agente crítico. Aprueba, revisa con feedback o cancela.

Git checkpointing

Commit automático tras cada paso completado. Rollback al SHA del paso si algo falla.

Scripts determinísticos

Pasos sin IA: quality-score, budget-guard, validaciones, índices de archivos.

Coste estimado antes de ejecutar

Tokens mínimos que recibe cada paso y la media real de las ejecuciones anteriores, con su precio si usas Claude.

Timeouts por paso, reintentos y cancelación

Un agente colgado ya no bloquea el pipeline: tiempo límite por paso y total, reintentos ante errores pasajeros y parada inmediata al cancelar.

04
MCP — Herramientas
externas, nativas.

Configura servidores MCP (stdio o HTTP/SSE) y asocia sus herramientas a agentes concretos. Claude Code y Copilot CLI los reciben en cada ejecución sin tocar tus ajustes; con las APIs, Agent Hub gestiona los procesos en un pool con refcounting, sin cold starts entre pasos.

search_repositories github MCP
query postgres MCP
fetch fetch MCP (built-in)
create_entities memory MCP (built-in)
