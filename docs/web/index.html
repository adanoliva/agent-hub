El problema

Desarrollar con IA hoy es caótico

Los agentes se crean manualmente, se pierden y no se reutilizan entre proyectos.

Cada proyecto acaba con configuraciones distintas y desincronizadas.

El conocimiento de cómo usar bien la IA queda en la cabeza de cada persona. No se comparte.

Los prompts se escriben a ojo, sin optimización ni base profesional de partida.

Automatización de navegador

Los agentes pueden controlar un navegador real vía CDP: navegar, hacer clic, rellenar formularios y capturar pantalla.

Orquestaciones multiagente

Encadena agentes en workflows secuenciales. El output de cada agente alimenta al siguiente, con rollback granular y auditoría completa.

Subsistema CLI

Cualquier proveedor de IA opera sobre el filesystem del proyecto con las mismas capacidades que una CLI nativa. Sin dependencias extra.

Gates HITL

Puntos de revisión humana entre pasos de una orquestación. Aprueba, pide que rehaga con feedback, o cancela — el tiempo de espera no consume timeout.

Scripts determinísticos

Nodos sin IA: analiza el proyecto, genera índices de archivos, valida JSON, calcula quality scores. Instantáneos y sin consumo de tokens.

Quality Score automático

Puntuación 0–100 calculada tras cada paso IA: respuesta producida, archivos modificados, JSON válido. Verde / ámbar / rojo sin llamar a la IA.

Git Checkpointer

Commits automáticos tras cada paso cuando gitEnabled está activo. Rollback exacto vía git reset --hard a cualquier punto de la ejecución.

Ops Ledger

Registro append-only de cada operación atómica: qué fichero cambió, qué agente lo hizo, en qué paso, con estado applied o reverted.

Scripts determinísticos

Nodos sin IA en el workflow

Intercala scripts Node.js entre agentes: analiza el proyecto, genera índices de archivos, valida JSON, calcula quality scores… sin gastar un solo token. 6 scripts incluidos.

prepare-context generate-file-index validate-json quality-score diff-since-step validate-output
Gates HITL

Revisión humana entre pasos

Activa un gate en cualquier conexión y la orquestación se pausa para que revises lo que hizo el agente. Aprueba, pide que lo rehaga con feedback (revertiendo automáticamente) o cancela. El tiempo de espera no descuenta del timeout.

Aprobar Revisar + rehacer Cancelar
Quality Score

Puntuación automática por paso

Tras cada paso IA, Agent Hub calcula un score 0–100 sin llamar a la IA: respuesta producida, JSON válido, archivos modificados, longitud sustancial. Badge verde / ámbar / rojo en la UI.

Git Checkpointer

Commits automáticos por paso

Con gitEnabled activo, cada paso genera un commit firmado por AgentHub. El rollback usa git reset --hard al SHA exacto — más preciso que cualquier snapshot.

Ops Ledger

Trazabilidad total de cambios

Registro append-only de cada operación atómica: qué fichero, qué agente, en qué paso, con estado applied o reverted. Persiste entre ejecuciones. Accesible desde la UI y vía API.

Reanudar ejecuciones

Continúa donde lo dejaste

Ejecuciones interrumpidas por error de red, cierre de la app o timeout parcial pueden reanudarse desde el último paso completado. El estado se persiste tras cada paso automáticamente.
