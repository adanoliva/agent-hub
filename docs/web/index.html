El problema

Desarrollar con IA hoy es caótico

Los agentes se crean manualmente, se pierden y no se reutilizan entre proyectos.

Cada proyecto acaba con configuraciones distintas y desincronizadas.

El conocimiento de cómo usar bien la IA queda en la cabeza de cada persona. No se comparte.

Los prompts se escriben a ojo, sin optimización ni base profesional de partida.

Funcionalidades

Todo lo que necesitas, en una sola app

Contexto Maestro

Un único archivo CONTEXTO.md sincronizado automáticamente con todas tus herramientas (CLAUDE.md, GEMINI.md, Copilot).

Multi-Proveedor IA

Soporte nativo para Claude, Gemini, OpenAI, DeepSeek y proveedores personalizados compatibles.

Gestión de proyectos

Organiza por categoría y tecnología. Abre en VS Code con un clic.

Editor de agentes

Crea y edita agentes con asistencia de IA integrada. Campos guiados.

Generación con IA

Describe lo que necesitas en lenguaje natural y la IA escribe el prompt completo.

Sync automático

Los agentes se sincronizan a todos los proyectos que los usan. Un cambio, efecto global.

Chat integrado

Consulta a la IA con @mention de agentes y contexto del proyecto. Indicador de estado de contexto y mismatch de proveedor.

Directorio de agentes

Descarga un catálogo curado de agentes profesionales, siempre actualizados.

Dashboard

Vista de inicio con métricas, salud de proyectos en tiempo real, oportunidades de mejora con opción de aplazarlas y acciones rápidas.

Seguimiento de uso IA

Tokens enviados y recibidos, coste estimado, por sesión y acumulado.

Automatización de navegador

Los agentes pueden controlar un navegador real vía CDP: navegar, hacer clic, rellenar formularios y capturar pantalla.

Orquestaciones multiagente

Encadena agentes en workflows secuenciales o paralelos (DAG). Canvas interactivo con aristas Bézier, rollback granular y auditoría completa.

Ejecución paralela DAG

Los agentes sin dependencias entre sí se ejecutan en paralelo por niveles topológicos. Más velocidad, misma trazabilidad paso a paso.

Subsistema CLI

Cualquier proveedor de IA opera sobre el filesystem del proyecto con las mismas capacidades que una CLI nativa. Sin dependencias extra.

Gates HITL

Puntos de revisión humana entre pasos de una orquestación. Aprueba, pide que rehaga con feedback, o cancela — el tiempo de espera no consume timeout.

Scripts determinísticos

Nodos sin IA: analiza el proyecto, genera índices de archivos, valida JSON, calcula quality scores. Instantáneos y sin consumo de tokens.

Quality Score automático

Puntuación 0–100 calculada tras cada paso IA: respuesta producida, archivos modificados, JSON válido. Verde / ámbar / rojo sin llamar a la IA.

Git Checkpointer

Commits automáticos tras cada paso cuando gitEnabled está activo. Rollback exacto vía git reset --hard a cualquier punto de la ejecución.

Ops Ledger

Registro append-only de cada operación atómica: qué fichero cambió, qué agente lo hizo, en qué paso, con estado applied o reverted.

Cómo funciona

De la idea al agente en menos de un minuto

01

Describe

Escribe qué necesita hacer el agente en lenguaje natural.

"Quiero un agente que revise mis commits antes de hacer push"
02

La IA genera

Agent Hub llama al proveedor de IA configurado y genera el system prompt completo y optimizado.

03

Asignas

Eliges el nivel: global, categoría o proyecto. La especificidad tecnológica se añade con skills inyectadas.

04

Sincronizas

La app copia el agente a todos los proyectos correspondientes automáticamente.

05

Usas

El agente está disponible desde tu editor y asistente de IA preferido.
